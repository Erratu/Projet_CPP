# Projet CPP

## Description
Simulation de particules dans un univers avec affichage graphique via ParaView.

## Structure
- `src/` : code source
- `include/` : headers
- `test/` : tests gtest
- `doc/` : documentation et analyse
- `src/` : fichiers de demo, créent des fichiers vtk dans build

## Compilation
cd build

cmake ..

make
